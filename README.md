# dark-theme
## 🚀 How to Install and Use This Extension

Because this extension is directly compiled from source code, you can easily install it locally in less than a minute. Follow these steps:

### 1. Download the Code
* Click the green **Code** button at the top right of this GitHub page.
* Select **Download ZIP**.
* Extract the downloaded `.zip` file into a folder on your computer (e.g., your Desktop or Documents folder).

### 2. Enable Developer Mode in Chrome
* Open Google Chrome.
* In the address bar, type `chrome://extensions/` and press **Enter**.
* In the top-right corner of the Extensions page, toggle the **Developer mode** switch to **ON**.

### 3. Load the Extension
* In the top-left corner, click the **Load unpacked** button.
* Select the folder you extracted in Step 1 (make sure you select the folder that directly contains the `manifest.json` file).
* Click **Open** or **Select Folder**.

### 4. Start Using It!
* Click the **Extensions puzzle piece icon** in the top-right corner of your Chrome toolbar.
* Find **Universal Theme Customizer** and click the **Pin** icon next to it for quick access.
* Open any webpage or online PDF, click the extension icon, and select your theme!

---

### ⚠️ Crucial Note for Local PDFs
If you want this extension to work on local PDF files stored on your hard drive (URLs starting with `file:///`), you must grant it permission:
1. Go to `chrome://extensions/`.
2. Click the **Details** button on this extension.
3. Scroll down and turn **ON** the toggle for **Allow access to file URLs**.
